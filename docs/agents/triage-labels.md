# Triage 标签

Matt 工程技能使用五个标准 triage 角色。本文件把这些角色映射到本项目 GitHub Issues 中实际使用的标签。

| Matt skills 里的标签 | 本项目使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已足够清楚，可交给 agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人类实现或决策 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色时，使用本表右侧对应的 GitHub label。完成事项通过关闭 issue 表示，不使用 `done` label。
