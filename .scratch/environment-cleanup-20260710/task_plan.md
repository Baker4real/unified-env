## 决策

| 决策 | 理由 |
| --- | --- |
| 本轮先刷新只读报告，不直接迁移或删除 | 项目政策要求真实迁移必须基于最新 inventory、具体 dry-run 和具体项显式授权 |
| 过程文件放在 `.scratch/environment-cleanup-20260710/` | 项目 issue tracker 规则要求任务材料位于 `.scratch/<feature-slug>/` |
| 所有命令显式 `Set-Location` 或使用绝对路径 | 执行器的 `workdir` 在本轮首次调用中未生效，曾导致扫描落到 `D:\` 根 |
| 暂不修改 readiness 生成器 | `brainstorming` skill 要求先给出设计并取得用户批准；本轮先完成根因和测试缺口证据 |
| 不依据当前 backup dry-run 做清理授权 | 脚本会静默跳过 `backups_state` 未识别目录，当前“3 项”不代表覆盖完整 |
| 不把 Python 仅按 D 盘路径判为共享运行时 | 当前 launcher 实际转发到 Hermes 项目 venv，违反项目本地环境隔离边界 |
| 第一批设计已获用户口头批准并写成文档 | 设计经多轮双子代理审查，已无 P0/P1 阻塞项；按 brainstorming gate 等待用户审阅已提交文档后再写实施计划 |
| CodeGraph 仅保留初始化空覆盖，Serena 作为本项目主语义导航 | CodeGraph 1.2.0 与官方最新 1.4.0 均不支持 PowerShell；用户明确选择 Serena 主导航，不采用伪语言索引或本地 fork |
| 实施采用 7 个 SDD 任务 | 每个任务独立 TDD、提交和任务评审；高风险任务增加对抗性审查 |

## 错误记录

| 错误 | 尝试 | 处理 |
| --- | --- | --- |
| 并发读取命令超时 | 1 | 拆分为窄范围读取 |
| `workdir` 未生效，`git`/`rg` 落到 `D:\` 根 | 1 | 后续命令显式 `Set-Location -LiteralPath` 并限制绝对路径 |
| PowerShell `foreach { } | Format-*` 解析失败 | 2 | 不再直接管道化 `foreach` 语句，先赋给数组变量后格式化 |
| 旧 memory 记录的 rollout JSONL 路径不存在 | 1 | 使用可用 rollout summary 和当前主机状态，不依赖缺失原始会话文件 |
